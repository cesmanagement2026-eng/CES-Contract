Data Governance

Recommended source structure

  • Sheet1 is the only contract-data source (original 2-row header, Old/New Contract blocks, and appended web fields).
  • Vendor, Hospital, Site and Group come from Sheet1, while Master supplies Site/Hospital metadata for access selection.
  • Staff Data is the single source for profile + permission + multi-site access.
  • 07_Notification_Config stores site reminder settings.
  • 08_Contract_Files logs uploaded contract documents.
  • Keep Staff Data, Config Data and Master private. Notification Config, Audit Log and Contract Files are optional separate system tabs.
